# To-Do List 사이트 기획서

> 할 일을 저장해서 쓰는 To-Do 앱을 GitHub Pages로 배포하는 것을 전제로 한 기획서입니다.
> **GitHub Pages에서 구현 가능한 기능만** 정리했습니다.

---

## 1. 프로젝트 개요

| 항목 | 내용 |
|---|---|
| 프로젝트명 | (가칭) To-Do List |
| 목적 | 할 일을 추가·저장하고, 달력과 날짜별로 관리하는 할 일 앱 |
| 배포 방식 | GitHub Pages (정적 호스팅, GitHub Actions로 빌드 후 배포) |
| 저장소 위치 | 기존 `todo-lab` 저장소의 새 폴더 `planner/` |
| 데이터 저장 | 브라우저 `localStorage` (서버·DB 없이 각 방문자의 브라우저에 저장) |
| 사용자 | 누구나 (로그인 없이 바로 사용, 데이터는 각자 브라우저에만 저장) |
| 핵심 컨셉 | 달력으로 날짜를 고르면 그날의 할 일이 바로 보이는 가볍고 깔끔한 할 일 관리 |

### 구현 원칙

1. **React + Vite**로 만들고, 빌드 결과물을 GitHub Pages에 배포한다.
2. 모든 데이터는 `localStorage`에 자동 저장한다. 읽기/쓰기는 `try/catch`로 감싸고, 저장소를 쓸 수 없으면 메모리로만 동작한다.
3. 데이터는 이 브라우저에만 있으므로, **JSON 백업 기능을 기본 기능으로** 둔다.
4. 처음 접속하면 짧은 안내와 예시 할 일 몇 개를 보여주고, 바로 지울 수 있게 한다.
5. **개인정보를 기본값으로 넣지 않는다.** 이름 등은 비워 두고 방문자가 직접 입력한다.

### 작업 범위 (건드리지 않는 것)

- 새 앱은 `planner/` 폴더 안에서만 만든다.
- 과제용 3티어 앱인 `web/`, `api/`, `k8s/`, `compose.yaml`, `Dockerfile`, `nginx.conf`는 수정하지 않는다.
- `.github/workflows/pages.yml`은 planner가 기존 데모보다 완성도가 높아졌을 때 planner를 배포하도록 바꾼다. (그 전까지는 기존 데모가 공개 상태로 유지됨)
- `vite.config.js`의 `base`는 `process.env.VITE_BASE || '/'`로 설정한다. (Pages 배포 시 `/todo-lab/`)

## 3. 달력 기능 명세 (핵심)

오른쪽 패널(넓은 화면) 또는 오른쪽에서 밀려 나오는 패널(좁은 화면)에 **월간 달력**을 둡니다.

| 상황 | 동작 |
|---|---|
| 페이지를 열었을 때 | **오늘 날짜가 자동으로 선택(active)** 되어 있고, 달력 아래에 오늘의 할 일이 보임 |
| 날짜를 클릭했을 때 | 선택(active) 표시가 클릭한 날짜로 이동하고, **달력 바로 아래에 그날의 할 일 목록을 표시**함. 가운데 목록은 사이드바에서 고른 보기를 유지 |
| 달력 아래 날짜 제목 | 선택한 날짜와 개수를 표시 (예: `11월 2일 (월)`, `3개`) |
| 달력 아래 할 일 | 체크박스, 제목, 리스트 태그를 작게 한 줄로 표시. 여기서 체크하면 완료 처리됨 |
| 할 일이 없는 날 | "이 날은 할 일이 없어요" 안내 표시 |
| 할 일이 있는 날 | 날짜 아래에 작은 색 점 표시 (모두 완료한 날은 연한 점) |
| 오늘 표시 | 다른 날짜를 선택해도 오늘은 얇은 테두리로 계속 구분됨 |
| 이전 달 / 다음 달 | (아직 구현 안 됨) 화살표로 이동, 달을 바꿔도 선택한 날짜는 유지 |
| 오늘 버튼 | (아직 구현 안 됨) 누르면 오늘 날짜로 바로 복귀 |
| 새 할 일 추가 | 날짜를 클릭하면 추가 카드의 날짜도 그 날짜로 바뀜. 사이드바에서 보기를 바꾸면 그 보기의 기본 날짜로 돌아감 |
| 지난 날짜 선택 | 달력 아래에서 그날 완료한 할 일과 못 끝낸 할 일을 확인 가능 |
| 날짜가 없는 할 일 | 달력에는 나오지 않고 All의 "날짜 없음" 묶음에서 확인 |
| 사이드바 Today 클릭 | 달력도 오늘 날짜 선택 상태로 이동 |

```
- 검색                       - 오늘 진행률 바 (모든 보기)             (오늘 active, 날짜 클릭)
- All                        - 보기 제목                            - 선택한 날짜의 할 일 목록
- Today / Upcoming           - 안내 (첫 접속 때)                      (날짜 제목 + 개수, 체크 가능)
- 리스트 (아이콘 + 개수)      - 필터 칩                             - 통계 카드

                              - (서브태스크, 태그, 날짜 태그)
```

## 9. 디자인 방향

다음 단계에서도 이 방향을 따릅니다.

**우선순위**

- 색과 레이아웃은 이 문서를 따릅니다.
- 접근성(글자 대비 4.5:1 이상, 포커스 링, 키보드 조작)은 `DESIGN-mobbin.md`를 따르며, 충돌하면 접근성이 우선합니다. 아래 표에 예외로 적은 곳만 디자인 결정을 따릅니다.
- 참고 이미지: 레이아웃과 구도는 `docs/레퍼런스1.webp`, `docs/레퍼런스2.webp`, 색감은 `docs/색_레퍼런스.webp`
- 이미지의 사람 사진, 일러스트, 로고, 이름과 문구는 가져오지 않습니다. 오른쪽 위 프로필은 두지 않습니다.

**레이아웃**

- 3단 구성: 왼쪽 사이드바(폭 280px) / 가운데 목록 / 오른쪽 달력 패널. 오른쪽 패널만 보조 바탕색을 씁니다.
- 사이드바 맨 위 "To-Do List"는 26px로 크고 굵게 씁니다.
- 가운데 영역은 좌우 여백 24~32px(폭 840px 이하는 16px), 최대 폭 1400px입니다. 제목과 콘텐츠의 왼쪽 시작선을 맞춥니다.
- 오른쪽 패널: 달력 바로 아래에 선택한 날짜의 제목, 개수, 할 일 목록을 둡니다. 할 일은 체크박스, 제목, 리스트 태그를 작게 한 줄로 표시합니다.
- 가운데 맨 위에 인사말을 둡니다: 20px "안녕하세요!" + 굵고 큰 "오늘 할 일 N개". 그 바로 아래에 오늘 진행률을 모든 보기에서 보여 줍니다. 날짜 문구는 두지 않습니다.
- 인사말 영역은 8px 단위로 묶습니다: 인사 → 제목 줄 8px, 제목 줄 → 바 8px.
- 진행률 글자는 "33%"처럼 퍼센트만 둡니다. 제목과 같은 줄 오른쪽 끝에 놓고 기준선을 맞추며, 포인트 컬러 22px 굵게 씁니다. "오늘 진행률"과 "완료" 글자, 개수는 화면에 표시하지 않습니다.
- 진행률 바는 제목 줄 바로 아래에서 가운데 영역 가로를 끝까지 채웁니다.
- 완료한 할 일이 아래로 내려가는 등 자리가 바뀌면 0.2초 동안 부드럽게 움직입니다. `prefers-reduced-motion`이면 바로 바뀝니다.
- 섹션 제목은 크고 굵게 씁니다. 가운데 영역에는 보기 전환 탭을 두지 않습니다.
- 카드는 흰색, 모서리 16~20px, 테두리 대신 아주 옅은 그림자를 씁니다.
- 버튼 배치: 할 일 추가 카드와 수정 영역은 날짜·리스트 선택을 왼쪽 끝, 추가 또는 취소·저장을 오른쪽 끝에 두고 한 줄에 놓습니다. 오른쪽 버튼은 줄어들지 않고, 공간이 모자라면 왼쪽 선택이 줄어들며 글자를 말줄임(…)합니다.
- 버튼 여백: 취소, 저장, + 추가는 `flex-shrink: 0`, 안쪽 좌우 여백 16px, 최소 폭 64px, 버튼 사이 간격 8px입니다.
- 둥글기와 높이: 입력창, 셀렉트, 합친 버튼, 취소, 저장, + 추가는 넓은 화면과 좁은 화면 모두 모서리 12px, 높이 44px입니다(`--control-radius`, `--control-height`).
- 합친 버튼: 화면 폭 600px 미만이면 할 일 추가 카드와 수정 영역이 동시에 날짜·리스트 선택을 버튼 하나로 합칩니다. 600px 이상은 셀렉트 두 개입니다. 1줄은 입력창, 2줄은 왼쪽에 합친 버튼, 오른쪽 끝에 취소·저장(추가 카드는 + 추가)입니다.
- 합친 버튼 표시: [달력 아이콘] 오늘 · [리스트 아이콘] [아래 화살표 아이콘] 형태로 줄바꿈 없이 짧게 씁니다. 날짜는 "오늘", "내일", "11/18", 날짜 없음은 "—"입니다. `aria-label`에는 전체 값을 넣습니다(예: "날짜 오늘, 리스트 Work, 변경하기").
- 선택 시트: 합친 버튼을 누르면 아래에서 올라오며, "날짜"(오늘/내일/직접 선택/날짜 없음)와 "리스트"(아이콘 + 전체 이름) 두 구역을 둡니다. 고르면 바로 반영되고, 완료 버튼, 바깥 클릭, Esc로 닫습니다. 열릴 때 포커스는 시트 안으로, 닫히면 합친 버튼으로 돌아갑니다.
- 달력 정렬: 날짜 칸과 요일 칸은 32px로 고정하고, 7개 열을 양 끝에 붙여 균등하게 둡니다(`justify-content: space-between`). 일요일 원의 왼쪽 끝은 "2026년 11월" 제목의 왼쪽 끝에, 토요일 원의 오른쪽 끝은 패널 콘텐츠의 오른쪽 끝에 맞춥니다. 요일 글자는 날짜 원의 가운데에 옵니다. 좁은 화면의 패널도 같습니다.
- 달력은 일요일 시작이고 모든 날짜 칸의 크기가 같습니다. 고른 날짜는 지름 32px의 `#0A6FD8` 원에 흰 글자, 오늘은 같은 크기의 1px 테두리(`#C9CDD3`), 할 일이 있는 날은 원 바로 아래 가운데에 작은 색 점(모두 완료면 연한 점)으로 표시합니다.
- 포커스 링은 키보드로 이동할 때만(`:focus-visible`) 포인트 컬러로 보여 줍니다.
- 확인 창과 안내: 되돌릴 수 없는 동작은 확인 창을 거치고(처음 포커스는 취소), 복원 같은 결과 안내는 하단에 잠깐 보여 줍니다.
- 진행률 바는 높이 4px, 양 끝은 완전히 둥글게, 바탕 `#DCE9FB`, 채움 `#1A8CFF`입니다. 그림자와 테두리는 없고, 0%에도 바탕이 보입니다. 채워질 때 0.3초 동안 부드럽게 늘어나고, `prefers-reduced-motion`이면 바로 바뀝니다.
- 앱 전체에서 이모지와 ▾ 같은 문자 대신 선 아이콘만 씁니다. 리스트 아이콘은 이름 앞에 두고, 아래 화살표는 chevron-down입니다. 아이콘은 `aria-hidden`이고 뜻은 버튼의 `aria-label`로 전합니다. 컨트롤 아이콘은 18px, 리스트 태그 안 아이콘은 14px입니다.
- 아이콘은 얇은 선 아이콘(Lucide, 선 굵기 1.5)으로 통일합니다. 여백은 넉넉하게 둡니다.
- 폭 1280px 이상: 오른쪽 패널을 고정으로 보여 주고, 떠 있는 달력 버튼은 숨깁니다.
- 폭 1280px 미만: 화면 오른쪽 아래에 고정된 동그란 달력 버튼(`aria-label="달력 열기"`)을 둡니다. 누르면 오른쪽에서 패널이 밀려 나와 달력과 선택한 날짜의 할 일 목록을 보여 줍니다.
- 패널이 열리면 뒤 화면은 반투명하게 어둡게 합니다. 닫기(X) 버튼, 바깥 클릭, Esc로 닫습니다. 열릴 때 포커스는 패널 안으로, 닫히면 달력 버튼으로 돌아갑니다.
- 폭 840px 이하: 1단 + 햄버거 메뉴 + 위와 같은 달력 버튼과 패널입니다.

**색** (`planner/src/styles.css`의 `:root` 변수 한 곳에서 관리)

| 용도 | 값 |
|---|---|
| 포인트 (글자가 없는 곳) | `#1A8CFF` (`--accent`) |
| 흰 글자가 올라가는 파란 바탕 | `#0A6FD8` (`--accent-strong`), 대비 4.9:1 |
| 위 바탕에 마우스를 올렸을 때 | `#085CB5` (`--accent-strong-hover`) |
| 파란 바탕 위 글자와 아이콘 | `#FFFFFF` (`--on-accent`) |
| 제목 글자 | `#2A2D3A` |
| 본문 글자 | `#4C4C4C` |
| 완료·보조 글자 (완료 항목, 삭제 시점에만. 대비 2.3:1 예외) | `#A8A8A8` |
| 바탕 / 보조 바탕 | `#FFFFFF` / `#F5F6F8` |
| 마우스 올린 줄 / 구분선 | `#EEF0F2` / `#EFEFEF` |
| 태그 칩 | 바탕 `#E9EAEC` + 작은 글자, 둥근 칩 |
| 기한 지남 칩 | 바탕 `#FDECEC` + 글자 `#B3261E` |
| 오늘 칩 | 바탕 `#E6F6EC` + 글자 `#1B6E3C` |
| 우선순위 별표 | 빨강 `#E5383B` |

**포인트 컬러 사용법**

파란 바탕 위의 글자와 아이콘은 모두 흰색입니다. `#1A8CFF`와 흰색의 대비는 3.4:1이라, 흰 글자가 올라가는 바탕은 `#0A6FD8`을 씁니다(4.9:1).

| 대상 | 표현 |
|---|---|
| 추가, 저장, 확인 같은 주요 버튼, 달력에서 고른 날짜 | `#0A6FD8`로 채우고 흰 글자, 마우스를 올리면 `#085CB5` |
| 진행률 바, 달력 점 | `#1A8CFF` |
| 떠 있는 달력 버튼 | `#1A8CFF`로 채우고 흰 아이콘, 마우스를 올리면 `#0A6FD8` |
| 진행률 퍼센트 숫자 | 포인트 컬러 글자 (22px 굵게, 큰 글자 기준 3:1 충족) |
| 체크된 체크박스 | 포인트 컬러로 채우고 흰 체크 아이콘 (아이콘은 3:1 기준) |
| 선택된 사이드바 메뉴 | 연한 바탕 + 포인트 컬러 글자와 아이콘, 세로선 없음 (디자인 결정으로 3.1:1 예외를 둠) |

**그 밖의 표현**

- **글꼴**: Pretendard, 대체 글꼴 Inter
- **상태**: 완료 = 흐린 글씨 + 취소선, 기한 지남 = 빨간 칩, 오늘 = 초록 칩, 진행률 = 가로 바
